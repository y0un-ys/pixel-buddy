# Pixel Buddy 🐾

귀여운 동물 친구가 컴퓨터를 함께 사용하는 Windows/macOS 데스크톱 펫.

**개발 버전:** v0.4.9 · **개발 브랜치:** `dev` (안정 버전만 `main`에 병합)

## 현재 기능

- 동물 5종: 고양이, 강아지, 곰, 여우, 토끼
- 새 3/4 반측면 캐릭터 PNG: `assets/illustrations/{cat,dog,bear,fox,rabbit}.png`
- 공통 `BuddyScene`에서 메인 화면·상점 미리보기·인벤토리 미리보기 렌더링
- 컴퓨터(노트북/데스크톱/듀얼), 책상, 소품, 테마 및 구매/장착 시스템
- 타이핑/마우스/게임/영상 시청/휴식 상태 감지 및 성장/코인
- 이전 저장 데이터 경로와 호환

## v0.4.9 — 상점 의상·액세서리·방송 소품 8종

- 기존 상점 카드(160×96)에는 아이템별 단독 PNG 썸네일을 표시합니다.
- 제품 이미지: `assets/shop/items/*.png` (300×320 투명 PNG × 8).
- 의상: 정장(기존 ID `suit`), 신규 스트릿패션(`streetwear`). 기존 아이템 ID·코인·레벨 조건을 유지합니다.
- 의상 장착 이미지: `assets/illustrations/suit/`와 `streetwear/` 동물별 각 5종. 기존 잠옷 5종도 그대로 사용합니다.
- 머리띠: 고양이 귀 헤드셋(`cat_ears`), 딸기 리본(`ribbon`), 토끼 귀 헤드셋(`bunny_ears`), 신규 게이밍 헤드셋(`gaming_headset`).
- 소품: 신규 방송용 마이크(`stream_microphone`) 및 링라이트(`ring_light`).
- 기존 미리보기는 구매하지 않고도 착용·배치 상태를 확인합니다. 구매/장착은 버튼을 누를 때만 이루어집니다.
- 기존 저장 데이터와 ID를 호환하고, `main`에는 변경을 적용하지 않았습니다.
- 자동 테스트/Qt 캡처로 아이템 렌더링을 검증하지만 macOS/Windows 실기기에서 추가 확인이 필요합니다.

## v0.4.8 — 행동이 분명하게 보이는 애니메이션

- 타이핑: 두 앞발이 **번갈아 키보드로 내려가는** 4단계 동작, 책상 위 실제 키보드 키 표시.
- 마우스: 몸통의 원형 회전 대신 한쪽 앞발이 좌우로 짧게 움직이고 클릭 신호 표시.
- 영상 보기: 장착한 컴퓨터가 노트북이어도 시청 중에만 **모니터형 화면**으로 연출(구매/장착 정보는 그대로). 재생 UI, 진행바, 팝콘 복원.
- 네이티브 macOS/Windows 실행 화면은 사용자 기기에서 추가 검증이 필요합니다.

## v0.4.4 — 일러스트 앱 연결

- 확정된 귀여운 일러스트 5종을 **실제 앱에 연결**했습니다.
- 별도 SVG 의자·몸통·손 레이어를 제거하여 중복 그림과 떠다니는 손 문제를 방지했습니다.
- 책상, 컴퓨터, 소품을 그림 앞쪽에 렌더링하여 겹침 순서를 통일했습니다.
- 그림이 없는 이전 소스에서는 기존 SVG 장면으로 대체합니다.
- GitHub Actions에서 실제 Qt 위젯을 그려 PNG로 캡처하는 시각 검증 도구를 추가했습니다.
- 테스트: `python -m pytest -q` / 실제 화면 캡처: `python tools/preview_illustrated_pet.py`

**아직 남은 작업:** 새 PNG의 손 모양은 정적인 기본 자세입니다. 행동별 앞발 포즈와 의상·머리띠 전용 일러스트는 후속 버전에서 작업합니다. Mac의 실제 화면 동작과 항상 위 동작은 기기에서 추가 검증이 필요합니다.

## v0.4.5 — 활동 애니메이션 및 수면 판정 개선

- 자동 감지는 관찰된 키보드/마우스 이벤트만으로 `typing`/`mouse`를 판정합니다.
- 실제 입력이 없는 일반 대기(`idle`)에서는 Z 표시가 나오지 않습니다. 150초 이상 활동이 없을 때만 시각적으로 `sleep`을 표시합니다.
- 새 동물 PNG는 그대로 유지하고 키보드 타건, 마우스 클릭, 영상 재생, 게임 컨트롤러, 대기·수면 효과를 주변 장비에 표시합니다.
- 모든 효과는 동물 얼굴/팔을 덧그리는 대신 장비 위치에 맞춰 렌더링합니다.
- 설정의 **현재 상태**에서 감지된 행동, 키/마우스 마지막 이벤트 시간, Mac 입력 모니터링 권한을 확인할 수 있습니다.
- 입력한 문자 내용은 읽거나 저장하지 않습니다. macOS 입력 모니터링 권한이 없으면 자동 타이핑 감지가 작동하지 않을 수 있습니다.
- 수동 행동 선택으로 각 애니메이션을 확인할 수 있습니다.
- 자동화 테스트는 GitHub Actions에서 수행하며, `tools/preview_illustrated_pet.py`는 6개 상태와 2개 프레임을 실제 Qt 화면으로 저장합니다.

**알려진 제한:** 현재 캐릭터 PNG는 정지 일러스트입니다. 캐릭터 전체는 작게 움직이고 상태별 장비/연출이 반응하지만, 실제 앞발 관절을 움직이는 개별 프레임 애니메이션은 아직 제작하지 않았습니다.

## v0.4.6 — 실제 캐릭터 프레임 애니메이션

- **강아지 귀 보정:** 기존 PNG의 오른쪽 귀가 이미지 경계에서 잘려 있던 문제를 복원했습니다.
- 동물 5종 × 행동 6종(타이핑/마우스/영상/게임/대기/수면) × 4프레임 = **120개의 실제 캐릭터 동작 프레임**을 5개 스프라이트 아틀라스에 수록했습니다.
- 기존 파스텔 일러스트를 바꾸지 않고, 머리 끄덕임, 앞발 타건/마우스 조작, 몸의 호흡, 게임 시 동작을 부드럽게 변형한 PNG 프레임입니다.
- 실제 게임 렌더러 `BuddyScene`이 `assets/animations/*.png`에서 행동별 프레임을 선택해 표시합니다.
- 컴퓨터 화면/커서/컨트롤러의 기존 효과도 그대로 유지됩니다.
- 애니메이션 이미지가 없으면 기존 단일 PNG로 안전하게 대체합니다.
- `tools/generate_chibi_animations.py`는 **개발자용** 이미지 재생성 스크립트입니다. 생성에는 Pillow/numpy/scipy가 필요하지만, **배포된 앱 실행이나 기존 Windows/Mac 빌드에는 필요하지 않습니다**. 새 시트는 `dev` 저장소에 이미 포함되어 있습니다.
- GitHub Actions에서 이미지 크기, 종별 모드 프레임의 실제 변화, 강아지 귀 잘림 여부와 Qt 화면 캡처를 검증합니다.

**현재 한계:** 리깅/모션은 기존 일러스트의 국소적 변형을 이용한 첫 번째 프레임 애니메이션입니다. 새로 그린 독립된 손·표정·걷기 포즈 시트는 다음 작업입니다.

## v0.4.7 — 더 크게 움직이는 캐릭터와 강아지 귀 복원

- 기존 v0.4.6의 2FPS·미세 흔들림을 개선하고 **4FPS(0.25초 간격)**로 동작별 포즈를 순환합니다.
- 고양이·강아지·곰·여우·토끼의 **6개 상태 × 4프레임** 캐릭터 PNG를 다시 생성했습니다.
- 타이핑에서는 양쪽 앞발이 교대로 움직이고, 마우스에서는 오른쪽 앞발을 오른쪽으로 내밉니다.
- 영상·게임에서는 팔과 고개 움직임을 더 크게, 휴식은 약하게, 수면은 고개를 숙이는 식으로 구분합니다.
- 캐릭터를 장면에서 더 크게 렌더링하여 작은 Mac 창에서도 움직임을 알아보기 쉽게 했습니다.
- 불필요한 타이핑 화살표 효과를 제거했습니다.
- 강아지는 과장되게 들린 귀 대신 **좋아했던 원본의 처진 귀 형태**를 복원했습니다.
- 애니메이션 생성기는 `tools/generate_chibi_animations.py`이며, GitHub Actions가 `assets/animations/`을 재생성합니다.

**현재 구현 방식:** 확정된 일러스트의 실제 앞발·머리 픽셀을 국소 변형하여 포즈를 바꿉니다. 아직 행동별로 완전히 새로 그린 독립 일러스트는 아니므로, 다음 단계에서 더 큰 팔 관절·표정 전환을 제작할 수 있습니다.

**Mac 테스트:** `git switch dev && git pull origin dev && bash build_mac.command` 이후 앱을 종료 후 재실행하세요. 설정에서 행동을 수동 선택해 4개 프레임을 먼저 확인하고, 자동 감지의 키보드 권한은 따로 확인하세요.

## 실행/빌드

Python 3.11 이상 필요.

### macOS (Apple Silicon 또는 Intel)

```bash
git clone -b dev https://github.com/y0un-ys/pixel-buddy.git
cd pixel-buddy
bash build_mac.command
open dist/PixelBuddy.app
```

이미 체크아웃했다면 `git switch dev && git pull origin dev` 후 빌드하세요.

macOS Gatekeeper가 미서명 `.command`를 차단하면 Finder 더블클릭 대신 위의 `bash build_mac.command`를 사용하세요. 입력 감지에는 macOS **개인정보 보호 및 보안 → 입력 모니터링** 권한이 필요할 수 있습니다. 입력 글자는 저장하지 않습니다.

### Windows

`build_exe.bat` 실행 후 `dist/PixelBuddy.exe` 실행.

## 개발 및 검증

```bash
python -m pip install -e . pytest
python -m pytest -q
```

CI는 Linux에서 자동화 테스트와 오프스크린 Qt 캡처를 실행합니다. 실제 Windows/macOS 실행과 패키징은 해당 OS에서 별도로 확인해야 합니다.

`main`은 안정 배포용으로 유지하며, 기능 개발은 `dev`에 커밋합니다. 자동 업데이트는 아직 포함되어 있지 않습니다.
